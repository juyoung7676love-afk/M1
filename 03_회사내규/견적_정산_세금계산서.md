# 견적 · 제안서 · 정산 · 세금계산서

> 한 줄 요약: 네이버는 광고주가 직접 충전하므로 VAT·송금이 없고 견적엔 우리에게 입금되는 비용만 적는다. 수수료는 네이버·카카오는 매체가 주고(조정 불가), 메타 등은 우리가 받으므로 조정 가능.

## 견적 · 제안서 작성
- **네이버**는 광고주 직접 충전 방식 → 광고비에 VAT가 붙지 않음(우리에게 송금할 필요 없음)
  - 제안서에 **"광고주 직접 충전 방식"을 명시**
  - 하단 공급가액 등에는 **우리에게 입금되는 비용만** 기재
- **소재 제작 건수**(숏폼 영상/이미지 월 몇 건)도 리소스 → 소요 시간을 고려해서 견적 산정
- 광고주가 내부에서 소재를 만들 수 있으면 소재 비용 별도 없음
- 총예산에 수수료+VAT가 모두 포함되면 광고비 = 총예산 ÷ 1.265 → [예산 계산](../04_기초개념/예산_수수료_VAT_계산.md)
- 예산 문의 시 광고비만인지, 전부 포함인지 확인 ([콜드콜 노하우](../01_콜드콜/콜드콜_노하우.md))

## 수수료 구조 (10/08)
| 매체 | 수수료 받는 방식 | 조정 |
|---|---|---|
| 네이버, 카카오 | 매체에서 지급 | 우리가 조정 불가 |
| 메타 등 | 광고주에게 입금받음 | 조정 가능 |

## 세금계산서
- 광고주가 우리에게 입금하면 → **우리가 발행**
- 네이버는 광고주 계정에 충전해서 쓰므로 광고비 입금이 필요 없음
- 세금계산서는 영수증 같은 개념 → "저희 측에서 오히려 세금계산서를 발행해 드려야 합니다!"
- **영수 발행**: 돈을 입금받은 뒤, 입금받았다는 의미로 발행
- **청구 발행**: "며칠까지 입금하겠다" → 받을 금액을 청구하는 의미로 발행

## 광고비 결제 · 계정 (메타 등)
- 광고주 비즈니스 포트폴리오(계정) → **광고주 카드**로 결제
- 광고주 카드 충전이 안 되거나 우리 회사 포트폴리오로 운영 → 광고주가 **우리에게 송금, 우리가 충전**
- 계정: 광고주 계정 / 새로 생성한 계정 모두 가능 (광고주 계정 = 광고주 카드, 우리 회사 계정 = 우리 회사 카드)
- ⚠️ 신규 계정은 신뢰도가 낮아서, 담배 같은 민감 업종은 신규 계정으로 하면 막힘

## 지원금(바우처) 광고 집행 방식
1. **광고주 돈으로 먼저 집행** → 이후 광고주가 지원금을 입금받음
2. **대행사 돈으로 먼저 광고 진행** → 진행 내역 전달 → 광고주가 그걸로 지원금 수령 → 받은 지원금을 우리에게 송금
   - 이 경우 **보증보험** 함께 진행
