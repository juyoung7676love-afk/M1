# 구글 앱 광고

- 앱 광고는 메타보다 **구글을 더 많이 씀**
- 구글은 CPI가 없고 거의 **CPA** 기반
  > ⚠️ 확인 필요: 구글 앱 캠페인에도 '설치' 목표와 타겟 CPI 입찰이 있음. 실무에서는 CPI보다 인앱 행동(CPA) 최적화를 주로 쓴다는 뜻인지 확인해 보기
- **전환 수 극대화 / 전환 가치 극대화** 둘 다 가능 → 객단가에 따라 선택
- 메타 대비 **전환당 비용이 상대적으로 잘 잡힘**
- J사 사례: CPC 254원, CPI 597원 ([사례](../09_실무/2026-10-15_다운도케어_앱광고_제안.md))
