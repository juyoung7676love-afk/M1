# 메타 소재 테스트 방법

> 한 줄 요약: 소액(일 5만 원 수준)이면 **광고 세트 하나에 확실히 다른 소재 2~3개**를 7일 이상 수정 없이 돌리고, 메타가 한쪽만 밀면 Push delivery나 크리에이티브 테스트 기능을 쓴다. 검증된 소재와 새 소재는 같은 세트에서 바로 붙이지 않는다.

## 테스트 방법 4가지 비교
### ① 메타 A/B 테스트(실험) 기능 — 꺼리는 이유
- 타겟·예산을 반반 나눠서 **예산이 많이 필요**, 소액이면 "유의미한 차이 없음"으로 끝나기 쉬움
- 공정 비교가 목적이라 잘 되는 쪽으로 예산을 몰아주지 않음
- 학습이 새로 시작, 테스트 중 수정 제한

### ② 캠페인·광고 세트를 따로 만들어 비교
- 실제 운영 조건에 가깝지만 타겟이 겹치면 **오버랩 문제** ([타겟 중복](타겟팅_타겟중복.md)), 엄밀한 비교는 아님

### ③ 한 광고 세트 안에 소재 여러 개
- 메타가 **하나 또는 소수 광고에 예산을 몰아줌** (광고 세트 전체 결과 최대화 목적)
- 장점: 예산 분산 없음, 방향을 빨리 봄
- 단점: **공정한 비교가 아님**
  - 승자를 빨리 정해서 좋은 소재가 충분히 테스트받지 못하고 묻힐 수 있음
  - 예산 많이 받은 소재 = 초반에 노출하기 쉬웠던 소재일 수도 있음

### ④ 광고 세트 하나에 광고 하나씩
- 각 소재 예산이 보장되어 공정하지만 예산을 쪼갬
- **의견이 갈리는 문제** (분리했더니 성과가 더 좋았다는 테스트도 있음)
- 일 5만 원을 4개로 나누면 각각 12,500원 → 구매당 비용 1~2만 원대면 하루 1건도 안 나와 비교 불가 (단순 산수)
- 참고: 일 5만 원이면 합쳐도 주 50건은 어려우므로 "학습 분산"은 결정적 이유가 아님
> ⚠️ 정정: "1광고 1광고세트는 추천하기 어렵다(학습 분산)" → 의견이 갈리는 문제이고, 진짜 이유는 예산 산수

> **결론 (의견)**: 일 5만 원이면 **광고 세트 하나에 확실히 다른 소재 2~3개**가 현실적

## 소재 개수 · 기간 가이드 (실무 권장, 메타 공식 아님)
- 광고 세트 예산 하루 50달러 미만 → **소재 최대 3개**
- 하루 50달러 수준 → 확실히 다른 새 소재 2~3개
- 기간: **최소 7일 수정 없이**, 소재당 하루 구매 1건 정도 예산으로 **7~14일**
- 구매당 비용 약 2만 원 이하 → 소재 2~3개, 7일 / 그보다 비싸면 → 소재 2개, 14일까지
- 구매가 적으면 CTR, 클릭당 비용 등 앞단 지표도 같이 판단 (의견)
- 소재는 문구만 다른 게 아니라 **각도 자체가 다르게** (사진 vs 영상, 전체 세팅 vs 클로즈업)

## 순차 테스트 (한 번에 한 변수만)
- 1라운드: 무엇을 팔지 (예: 단품 vs 세트)
- 2라운드: 이긴 쪽으로 각도 (예: 감성 인테리어 vs 기능)
- 3라운드: 형식 → 사진 vs 짧은 영상
- 이후: 이긴 조합 유지 + 크리에이티브 테스트로 새 아이디어 하나씩
- 광고비 없이 미리 거르기: 인스타 오가닉 게시물 반응(저장·공유·댓글) 좋은 것을 소재 후보로
- 테스트 순서·판정 기준 제안서 문구: [ABO·ASC 운영 · 소재 기획](ABO_ASC_운영_소재기획.md)

## 기존 승자 소재 + 신규 소재
**상황**: A·B·C 중 A가 이겨서 B·C를 끄고 D·E를 추가
- 리셋되는 건 광고 세트 학습 카운트, **A 광고 자체의 성과 기록은 남음**
- 광고 품질은 그 광고를 본 사람들의 반응으로 판단 → **D·E는 불리한 출발선**
- 메타는 차이가 작아도 이긴 광고에 몇 배 많은 예산을 줄 수 있음
- 실무 가이드: **이미 검증된 소재와 새 소재를 같은 광고 세트에서 바로 붙이지 말 것**

## 해결책 (광고 세트 하나 유지)
### Push delivery (이 광고에 노출 집중)
- 광고가 2개 이상일 때 사용 가능
- 예산 일부를 특정 광고에 **최대 7일** 강제 배정

### 크리에이티브 테스트 기능
- 광고 생성 화면 하단 "크리에이티브 테스트"
- **최대 5개** 버전 비교, 테스트 광고 수·예산 비중·기간·비교 지표 설정
- 기존 광고 세트 안에서 진행, 테스트 기간 중 테스트 소재끼리 예산 고르게 배분
- 메타 권장 테스트 예산: **20% 이내**
- 제약: **이미 돌고 있는 광고는 테스트 불가** (복제본으로 새로 만든 광고만), 테스트 후 이긴 광고를 밀어준다는 보장 없음
- 일 5만 원의 20% = 1만 원 → 소재 2개면 각 5천 원. 구매 비교엔 부족하니 CTR·CPC로 판단하거나 기간을 길게

## 단품 소재 vs 세트 소재가 한 세트에서 경쟁할 때
### 문제
- 기본 목표(**전환 수 최대화**)에서 메타는 **구매 건수만** 봄
- 단품이 싸게 많이 팔리면 세트가 주문당 더 남아도 단품으로 예산이 몰림

### 무조건 손해는 아님
- 단품이 훨씬 싼 CPA로 많이 팔리면 총 이익이 더 클 수 있음
- 비교 기준: **소재별 (구매 건수 × 주문당 마진) − 광고비**
- 단품 상세페이지에 **"세트로 사면 이득"** 안내 → 어느 소재가 이기든 세트로 유도

### 근본 해결: 가치 최적화 (Maximize Value)
- 구매 건수보다 **구매 금액이 높은 쪽**을 우선
- 조건: 최근 7일간 **서로 다른 구매 금액 2개 이상** + 7일간 **클릭 기반 기여 구매 30건 이상**
- 일 5만 원 초반엔 30건이 어려움 → 데이터 쌓인 후 전환
- 가치 최적화 시 구매당 비용은 올라갈 수 있음 (건수 감소)
