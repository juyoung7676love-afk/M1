# 스마트스토어 × 메타 픽셀 — 킵그로우

> 한 줄 요약: 스마트스토어엔 메타 픽셀을 직접 설치할 수 없어서, 구매 전환을 메타에 보내려면 킵그로우(픽셀샵) 같은 솔루션이 필요하다. 킵그로우는 페이지뷰·콘텐츠 조회·구매만 추적한다(장바구니 X).

## 문제
- **스마트스토어는 메타 픽셀 직접 설치 불가** (네이버가 관리하는 스토어)
- 픽셀이 없으면 구매 전환이 메타에 안 잡히고 판매 캠페인을 제대로 쓰기 어려움
- 구매 최적화·학습·CPA 조언은 모두 **구매 데이터가 메타에 들어온다는 전제** → 스마트스토어 광고주면 먼저 이것부터 해결
> ⚠️ 정정: 픽셀 전제로 구매 최적화를 조언했던 것 → 스마트스토어는 픽셀 설치 불가, 킵그로우 등 필요

## 해결 솔루션
| 솔루션 | 방식 |
|---|---|
| **킵그로우 "메타 구매전환 추적 AI 매니저" (픽셀샵)** | 네이버 기술 협약, 픽셀이 들어간 픽셀샵 경유 → 스마트스토어 → 구매 데이터 메타 전송 |
| 셀즈업 | 서버에서 메타 CAPI로 구매 이벤트 전송 |
| NT 파라미터 | 스마트스토어 통계에서 유입·전환 확인용. **메타 학습엔 쓰이지 않음** |

> ⚠️ 정정: "픽셀샵"과 "킵그로우"는 별개가 아니라 **같은 솔루션** (킵그로우가 만든 픽셀샵)

## 킵그로우 요금
- 월 고정 구독, **스마트스토어 판매자 등급별 요금**
- 첫 구매 시 등급 무관 **첫 달 베이직 29,900원**, 2회차부터 실제 등급 요금 자동 결제
- 결제: 네이버 커머스솔루션마켓 → 스마트스토어 비즈월렛
- 중도 해지 환불 없음 (해지 신청한 달까지 이용)
- 등급별 전체 요금표는 커머스솔루션마켓 상품 페이지에서 확인 필요
- **손익 계산에 구독료도 비용으로 포함** (베이직이면 하루 약 1,000원 꼴)

## 킵그로우 이용 조건
- 스마트스토어 운영자 계정 + 비즈머니 (쇼핑윈도 불가)
- 페이스북 ID + 인스타그램 프로페셔널 계정이 연결된 메타 비즈니스 계정, 광고 계정, 픽셀
- 협력광고 계정에선 외부 URL 경고 발생 → **일반 광고 계정**으로 진행

## 킵그로우 설정
- 기존 픽셀이 있어도 **킵그로우 전용 픽셀을 새로 생성**해 연결
- 광고 링크는 스마트스토어 주소가 아니라 **픽셀샵 URL** (`도메인/?productId=상품번호`로 특정 상품 강조)
- 각 광고를 해당 상품 픽셀샵 URL로 연결하면 소재별 성과 구분 가능
- 픽셀샵은 인기순 최대 71개 상품 반영, "라이브"·"특가" 카테고리 연동 불가
- 설치 확인: 이벤트 관리자 → 킵그로우 픽셀 → 구매 이벤트 → 샘플 활동 (테스트 구매로 확인 권장)

## 추적 범위
- **추적 이벤트: 페이지뷰, 콘텐츠 조회, 구매 3가지뿐**
- **장바구니 담기 최적화 불가** → 구매가 적을 때 대안은 **콘텐츠 조회** 최적화
> ⚠️ 정정: "구매 적으면 장바구니 담기로 최적화" → 킵그로우는 장바구니 이벤트 미지원
- **구매 금액까지 추적** → 나중에 가치 최적화 가능
- 픽셀샵 경유 후 **30일간** 해당 상품 및 함께 구매한 상품 추적
  - 추적 불가: 스마트스토어 창을 닫고 다른 채널로 재진입해 구매한 경우
- 특정 상품 조회자에게 같은 상품을 보여주는 리타겟팅은 불가, 픽셀 데이터로 타겟 생성은 가능
- 픽셀샵 경유 구매에 **스마트스토어 마케팅링크와 같은 수수료 할인** 적용
