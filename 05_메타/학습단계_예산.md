# 메타 학습 단계 · 일예산 · 캠페인 예산

> 한 줄 요약: 광고 세트가 주요 수정 후 7일 안에 최적화 이벤트 약 50건을 채우면 학습 종료. 그래서 일예산 ≈ 목표 CPA × 7~10이 경험칙이고, 캠페인 예산(구 CBO)은 테스트가 아니라 확장용이다.

## 학습 단계 (Learning Phase) 기준
- 광고 세트가 **마지막 주요 수정 후 7일 안에 최적화 이벤트 약 50건** → 학습 종료
- 못 미치면 **"학습 제한(Learning Limited)"** — 실패는 아니지만 성과가 불안정
- 학습 제한 자체는 실패 아님 → **실제 CPA가 손익분기 아래인지**가 기준

## 학습을 다시 시작시키는 "주요 수정"
- 타겟 변경
- 광고 소재 수정
- **새 광고 추가**
- 광고 세트 7일 이상 일시중지
- 예산 변경 (크기에 따라, 실무에선 **20% 이내** 조정 권장)

## 리셋의 범위
- **단위: 해당 광고 세트 하나만** (다른 광고 세트·캠페인은 영향 없음)
- 광고 하나를 수정해도 그 광고가 속한 광고 세트 전체가 학습에 들어감
- 리셋되는 것: **50건 카운트** (마지막 주요 수정 이후 전환만 다시 셈)
- 지워지지 않는 것: **픽셀 데이터** (계정 단위 데이터 소스)
- 메타가 재학습 때 이전 학습을 얼마나 재활용하는지는 **공개 자료 없음**
- "수정하면 0부터 다시"는 과장. Jon Loomer 테스트에서는 새 광고 추가 후에도 학습으로 돌아가지 않은 사례가 있음

## 소재 교체 실무
- **진 소재 끄기** → 주요 수정 목록에 없음 (메타가 명시적으로 "안 된다"고 한 문서는 못 찾음)
- **새 소재 추가·기존 소재 수정** → 학습 재시작 가능
- 소재를 바꾸려면 기존 광고를 고치지 말고 **새로 만들어 넣기**, 넣을 땐 **한 번에 몰아서**

## 일예산과 목표 CPA
**경험칙: 일예산 ≈ 목표 CPA × 7~10**
- 근거: 주 50건 ÷ 7일 → **일예산 ≈ 목표 CPA × 7.1**
- ×10은 여유를 둔 실무 경험칙 (메타 공식 규칙 아님, ×5를 최소로 보는 자료도 있음)

| 일예산 5만 원 기준 | 필요한 목표 CPA |
|---|---|
| ×10 기준 | 5,000원 이하 |
| ×7 기준 | 약 7,100원 이하 |

- 못 맞추면: 학습 제한 감수 / 더 자주 일어나는 이벤트로 최적화 / 예산 증액
- ×10은 "학습을 안정적으로 벗어나기 위한 기준"이지, 이보다 적으면 광고하면 안 된다는 뜻이 아님
- 목표 CPA 계산법: [CPA · ROAS · 손익분기](../04_기초개념/CPA_ROAS_손익분기.md)

## 캠페인 예산 (Advantage+ 캠페인 예산, 구 CBO)
- **총 지출은 늘지 않음** (같은 예산 안에서 배분만 달라짐)
- 성과 좋은 광고 세트에 예산을 더 옮김 → 메인 광고 세트로 몰리고 **테스트 광고 세트는 굶을 수 있음**
- 광고 세트별 최소·최대 지출 한도 기능은 있지만 메타도 특수한 경우에만 쓰라고 권장
- 실무 의견: 캠페인 예산은 **확장용, 테스트용이 아님**
- 소액이면 **광고 세트 하나 + 크리에이티브 테스트 기능 / Push delivery**가 적합 ([소재 테스트](소재_테스트.md))
