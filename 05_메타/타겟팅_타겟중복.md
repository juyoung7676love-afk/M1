# 메타 타겟팅 · 타겟 중복

> 한 줄 요약: 대중 상품·데이터 많은 계정은 넓게, 니치 업종·초반 계정은 관심 보인 사람 → 관련 관심사 → 유사 타겟 순으로 넓혀 간다. 같은 광고주 광고 세트끼리 타겟이 겹치면 한 세트만 경매에 나가 성과가 불안정해진다.

## 넓게 열어두는 게 잘 먹히는 조건
- 뷰티·패션·생활용품처럼 **누구나 살 수 있는 상품**
- 픽셀에 **구매 데이터가 많이 쌓인 계정**
- 이 경우 좁히면 메타가 고를 후보만 줄고 CPM 상승

## 니치 업종(예: 파충류)은 다름
- 살 사람이 소수 → 넓게 열면 그 소수를 찾을 때까지 시행착오 비용이 큼
- "파충류" 관심사는 변별력 있는 신호
- 넓게 열어도 "랜덤"은 아니지만, **초반 데이터가 없으면 헛발질이 생김**

## 소액·초반 추천 순서 (의견)
1. 이미 관심 보인 사람 (방문자, 인스타 참여자, 구매자 리스트)
2. 관련 관심사 묶어서 좁게 시작 (단, **너무 좁히지 않기** — 같은 사람에게 반복 노출되고 빨리 지침)
3. 구매 데이터가 쌓이면 유사 타겟 → 넓게 확장
- 소재로 한 번 더 거르기: 첫 화면에 타겟이 바로 알아볼 대상(예: 파충류·사육장)이 확실히 보이게

## 타겟 중복 (Auction Overlap)
- 메타는 같은 광고주의 광고 세트끼리 경매에서 맞붙게 하지 않고 **총 가치가 가장 높은 하나만** 내보냄
- 중복이 많으면 **비용 상승 또는 노출 부족** 둘 다 발생 가능 → 성과 불안정
> ⚠️ 정정: "CPM이 아니라 노출 부족 문제"라고 했던 것 → 비용 상승·노출 부족 **둘 다** 가능

**해결 방법**
- 타겟 중복 확인: 타겟 화면 → 여러 타겟 선택 → 작업 → **타겟 중복 표시**
- 제외 타겟 설정 (예: 신규 타겟에서 방문자·구매자 제외)
- 비슷한 광고 세트 합치기
- 캠페인 예산(Advantage+ 캠페인 예산) 사용 — 단, 비교 테스트 용도엔 부적합 ([학습 단계·예산](학습단계_예산.md))

## CTR은 괜찮은데 CPC가 높으면 타겟 점검
- 소재는 통하는데 노출(CPM)을 비싸게 사고 있다는 신호 → 타겟이 너무 좁거나, 경쟁이 몰리는 타겟이거나, 조건을 여러 겹 걸었거나, 광고세트끼리 겹치는지 확인
- 자세한 이유: [광고 지표와 퍼널](../04_기초개념/광고지표_퍼널.md)

## 반복 노출(빈도) 확인
- 같은 사람에게 반복 노출되는 건 학습 리셋이 아니라 **타겟이 작기 때문** → 빈도(Frequency) 지표로 확인
- 새 소재는 오히려 피로도를 낮춤
