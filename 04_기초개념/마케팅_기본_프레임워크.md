# 마케팅 기본 프레임워크

> 한 줄 요약: 실제 마케팅은 **환경분석 → STP → 전략 실행 → 브랜딩** 흐름으로 이어진다. 진단(환경분석·STP·PLC·수요 상황)을 먼저 하고, 처방(광고·브랜딩)은 그다음이다.

## 1. 환경분석 (현재 상황 파악)
- **3C**: 자사(Company)·고객(Customer)·경쟁사(Competitor) 분석
- **SWOT**: 내부의 강점·약점, 외부의 기회·위협 정리
- **PEST**: 정치·경제·사회·기술 등 거시 환경 분석
- **5 Forces**: 경쟁자, 신규 진입자, 대체재, 공급자·구매자 교섭력으로 산업 매력도 판단

## 2. STP (누구에게 어떻게 팔지)
- **세분화(Segmentation)**: 나이·지역·라이프스타일 등으로 시장을 나눔
- **타깃팅(Targeting)**: 그중 공략할 고객층 선택
- **포지셔닝(Positioning)**: 고객 머릿속에 "이 브랜드는 ○○"로 자리 잡게 함

## 3. PLC (제품 수명주기)
| 단계 | 마케팅 목표 |
|---|---|
| 도입기 | 인지도 쌓기, 시험 구매 유도 |
| 성장기 | 점유율 확대, 경쟁 대응 |
| 성숙기 | 차별화, 충성 고객 유지 |
| 쇠퇴기 | 비용 줄이기, 리뉴얼 또는 철수 |

## 4. 수요 상황별 마케팅 8가지 (코틀러)
| 마케팅 | 수요 상황 | 할 일 |
|---|---|---|
| 전환적 | 싫어하는 수요 | 좋아하게 |
| 자극적 | 무관심 | 관심 생기게 |
| 개발적 | 잠재 욕구 | 실제 상품으로 |
| 재마케팅 | 감소하는 수요 | 되살리기 |
| 동시화 | 불규칙한 수요 | 고르게 |
| 유지 | 적정 수요 | 지키기 |
| 억제적(디마케팅) | 과잉 수요 | 줄이기 |
| 대항적 | 해로운 수요 | 없애기 |

## 5. 브랜딩 프로세스
1. 브랜드 정체성(핵심 가치) 정의
2. 이름·로고·톤 등 요소 개발
3. 커뮤니케이션으로 인지도 형성
4. 브랜드 경험 관리로 충성도 확보

## 핵심: 진단 먼저, 처방은 나중
- 이 순서대로 **진단(1~4)을 먼저** 하고 **처방(광고·브랜딩)**을 해야 함
- 제안서에서 "시장을 얼마나 이해하는지" 보여주는 근거가 바로 이 진단 단계 → [제안서 작성 워크플로우](../03_회사내규/제안서_작성_워크플로우.md)
