# 광고 지표와 퍼널

> 한 줄 요약: **CPM → CTR → CPC → CVR → CPA** 순서로 노출 > 클릭 > 전환 퍼널을 따라가며, 어느 단계가 막혔는지 진단한다.

## 지표 공식
| 지표 | 공식 | 의미 |
|---|---|---|
| CPM | 광고비 / 노출수 × 1,000 | 노출 1,000회당 비용 (Cost Per Mille) |
| CTR | 클릭수 / 노출수 × 100 | 광고를 본 사람 중 클릭 비율 → **소재 매력도** |
| CPC | 광고비 / 클릭수 | 클릭당 비용 |
| CVR | 전환수 / 클릭수 × 100 | 클릭 후 전환 비율 → 랜딩·가격·신뢰도·구매 편의성 |
| CPA | 광고비 / 전환수 | 전환당 비용 |

## CPM 해석
- **CPM이 높다** = 노출 단가가 비싸다 (노출을 얻기 어렵다). 원인:
  1. 성수기라 광고 경쟁이 치열
  2. 타겟이 너무 좁음
- CPM이 높아도 **CTR이 높으면 CPC는 낮아질 수 있음** (CPC = CPM ÷ (1,000 × CTR))
- **CPM이 낮을 때** → 전환율을 봐야 함. 노출이 많아도 클릭·전환이 없으면 소용없음

## CTR · CVR 조합 진단
- CTR 높음 = 소재가 타겟에게 잘 먹힘(소재 경쟁력) → 이후 전환이 잘 나오는지 확인
- 전환이 낮다면: 랜딩페이지, 상품, 가격, 자극적 문구로 어그로만 끈 건 아닌지 점검

| CTR | CVR | 해석 | 액션 |
|---|---|---|---|
| 높음 | 낮음 | 과장 광고 or 랜딩페이지 약함 | 랜딩·상품·가격 점검 |
| 낮음 | 높음 | 구매 의지 강한 고객층 | 광고 소재 개선 |

## CPC와 CPA의 관계
- 노출 단가가 같다면 CTR이 높을수록 CPC가 내려감
- 클릭이 싸도 전환율이 낮으면 CPA가 비싸짐 / 클릭이 비싸도 전환율이 높으면 CPA는 괜찮음

## 유입 측정 — 광고로 얼마나 들어왔나
- **트래픽**: 광고를 보고 클릭해서 유입된 사람
- **브랜드 검색량**: 광고로 브랜드를 인지한 사람이 나중에 검색해서 유입 → 인지도 지표
- 메타의 클릭 vs 링크 클릭 구분: [메타 지표 메모](../05_메타/계정_권한_지표.md#클릭-vs-링크-클릭)

## 기타 개념
- **리타겟팅**: 구매 의지가 높아 CTR·CVR이 높고 CPA가 낮게 나올 가능성 큼. 단, 타겟 규모가 작음
- **간접전환**: 광고 클릭 후 일정 기간 뒤 구매한 경우. 고관여 제품일수록 많음
- **기여도(어트리뷰션)**: 고객이 여러 곳에서 여러 광고를 봤을 때 성과를 어디에 나눌지 정하는 방식
  - 라스트 클릭 / 퍼스트 클릭 / 선형 / 데이터 기반
  - 내 메모: 고객 마음을 모르는데 뭘 보고 샀는지 어떻게 알지? → 그래서 모델별로 해석이 달라지고, 데이터 기반 모델은 실제 전환 경로 데이터로 비중을 추정함
