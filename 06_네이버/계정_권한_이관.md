# 네이버 광고 계정 · 권한 · 이관

## 운영 전 확인 사항
- 광고주 **계정이 있는지**
- **연동시킬 URL**이 있는지
- 네이버는 광고주 계정에 직접 충전(비즈머니)하는 방식 → 우리에게 광고비 입금 불필요, VAT 없음 ([견적 메모](../03_회사내규/견적_정산_세금계산서.md))

## 조회 권한 받기
1. "네이버 광고주센터" 검색 → 메인 페이지 우측 상단 **운영관리** 버튼
2. **설정 > 권한관리 > 회원관리**
3. 본인 네이버 아이디를 광고주에게 전달 → 광고주가 추가

## 대행권 이관
- **(광고주)** 광고주센터 > 운영관리 버튼 > 비즈머니 충전 페이지 > 왼쪽 상단의 **숫자 아이디** 전달
- **(마케터)** 광고주센터 > 설정 > 영업 > 영업관리 > **대행권 이관요청** > 광고주 숫자 아이디 입력

## 콜 멘트
- "광고주센터 숫자 아이디 주시면 이관받아서, 담당자 오기 전에 제가 먼저 확인해 보겠습니다."

## 수수료
- 네이버 대행 수수료는 매체에서 지급 → 우리가 조정 불가
