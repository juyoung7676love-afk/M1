# 가공집(GGZ) 파충류 용품 — 메타 광고 플랜

> 한 줄 요약: 스마트스토어 기반 니치 상품(평균 구매 3만 원, 재구매 거의 없음). 킵그로우로 구매 추적부터 깔고, 일 5만 원·광고 세트 1개·소재 2~3개로 단품 vs 세트를 테스트하며, 한 달 성과는 ROAS 하나가 아니라 수익·구조 개선 지표까지 미리 합의한다.

## 스토어 관찰
| 상품 | 가격 | 비고 |
|---|---|---|
| 스카이라운지2 자석형 아크릴사육장 | 28,000원 (정가 30,000원) | 리뷰 4 |
| 락플랜트 탈피보드 식물꽂이 | 5,000원 | |
| 락케이브 은신처 | 12,000원 (정가 20,000원, 40% 할인) | 리뷰 1 |
| 락캐슬 | 25,000원 | 리뷰 9 |
| 배송비 | 3,500원 | |

- 평균 구매금액 30,000원, 재구매 거의 없음 → **첫 구매 마진만으로** 계산
- 국내 시장: 소형 은신처 2,800~9,000원대, 프리미엄 우드 은신처 40,000원 → 가공집은 **인테리어 감성형**으로 차별화

## 광고 관점 (의견)
- 강점: 실제 게코가 들어간 감성 사진 → 바로 소재로 활용 가능
- 핵심 타겟: 레오파드게코·펫테일·납테일 등 **바닥 생활형 게코** 사육자
- 객단가 올리기: 예) 락캐슬 + 락케이브 + 락플랜트 = 정가 42,000원 세트, 배송비 1회 또는 소폭 할인
- 걸리는 점: **리뷰가 적음** → 포토리뷰 이벤트 / 락케이브 40% 할인은 마진을 크게 깎음
- 리타겟팅 비중 고려: 꾸미기 용품은 고민 후 구매하는 경우가 많음
- 소재는 개별 제품보다 **완성된 사육장** 위주가 세트 구매로 이어지기 쉬움
- 타겟 전략: [타겟팅 · 타겟 중복](../05_메타/타겟팅_타겟중복.md) (니치 업종 → 관심 보인 사람부터)

## 인스타그램 계정 점검
### 프로필 소개 문구
- 현재 "3d용품점, 도매 문의 DM"만으로는 광고 보고 들어온 사람이 **뭘 파는 곳인지 알기 어려움**
- **대상과 제품을 명확하게** 적기
  - 예) "레오파드게코·크레 사육장 꾸미기 | 3D 프린팅 은신처 | 맞춤 제작"

### 프로페셔널 계정 여부 확인
- 킵그로우 이용 조건 ([킵그로우](../05_메타/스마트스토어_픽셀_킵그로우.md))
- 확인 방법: **프로필 편집 → 계정 유형이 "비즈니스" 또는 "크리에이터"**인지 확인

## 마진율별 손익분기 (평균 구매 30,000원)
| 마진율 | 주문당 남는 돈 | 메타상 손익분기 CPA | ×10 기준 일예산 |
|---|---|---|---|
| 30% | 9,000원 | 약 7,100원 | 약 7.1만 원 |
| 40% | 12,000원 | 약 9,500원 | 약 9.5만 원 |
| 50% | 15,000원 | 약 11,900원 | 약 11.9만 원 |

- 3만 원 주문에 CPA 5,000원 = **ROAS 6배** → 처음부터 기대하긴 어려운 수준
- 계산법: [CPA · ROAS · 손익분기](../04_기초개념/CPA_ROAS_손익분기.md), [일예산 경험칙](../05_메타/학습단계_예산.md)
- 총예산 200만 원(수수료+VAT 포함) → 실제 광고비 1,581,028원 ([계산](../04_기초개념/예산_수수료_VAT_계산.md))

## 일예산 5만 원 운영 구조 (의견)
1. **구조**: 판매 캠페인 1개 + 광고 세트 1개 (일 5만 원)
2. **소재**: 총 2~3개 (단품 1 + 세트 1~2), 각 광고는 **해당 상품 픽셀샵 URL**로 연결 (소재별 성과 구분)
3. **기간**: 7일간 수정 금지
4. **판단 기준**: CPA가 아니라 **주문당 남는 돈**과 ROAS
   - 예: 단품 CPA 12,000원 / 세트 CPA 16,000원이어도 세트 주문당 마진이 8,000원 더 크면 세트가 이득
5. **메타가 한쪽만 밀 때**: Push delivery 또는 크리에이티브 테스트 기능 ([소재 테스트](../05_메타/소재_테스트.md))
6. **최적화 이벤트**: 구매로 시작, 구매가 너무 적으면 콘텐츠 조회로 전환 검토. 학습 제한 자체는 실패 아님 → 실제 CPA가 손익분기 아래인지가 기준

**순차 테스트 (한 번에 한 변수만)**
- 1라운드: 단품 vs 세트 → 무엇을 팔지
- 2라운드: 이긴 쪽으로 각도 → 감성 인테리어 vs 기능(탈피·은신)
- 3라운드: 형식 → 사진 vs 짧은 영상
- 이후: 이긴 조합 유지 + 크리에이티브 테스트로 새 아이디어 하나씩
- 광고비 없이 미리 거르기: 인스타 오가닉 게시물 반응(저장·공유·댓글) 좋은 것을 소재 후보로

## 한 달 안에 성과 보여주기 플랜 (의견)
### 0주차: 준비 (2~4일, 새 촬영 시 일주일 안팎) (추정)
| 작업 | 예상 시간 | 비고 |
|---|---|---|
| 킵그로우 설치 | 반나절~1일 | 계정 조건이 갖춰진 경우. 테스트 구매로 이벤트 확인 권장 ([킵그로우](../05_메타/스마트스토어_픽셀_킵그로우.md)) |
| 세트 상품 등록 | 반나절~1일 | 세트 구성·가격 결정은 광고주 결정 필요 |
| 소재 준비 | 기존 사진 1일 / 새 촬영 3~5일 | |
| 광고 세팅 + 검수 | 1일 | 메타 검수 보통 하루 |

- 계정·결정이 필요한 작업은 **광고주에게 바로 요청해 병행**
- 1라운드는 **기존 사진으로 먼저 시작**, 새 촬영은 3주차 테스트용

### 1~2주차
- 단품 vs 세트, 구매 최적화, 7일 수정 금지

### 3~4주차
- 진 소재 끄고 이긴 쪽 유지
- 크리에이티브 테스트(20% 이내)로 새 각도 1개
- 구매가 너무 적으면 콘텐츠 조회 최적화 검토

### 성과 정의를 미리 합의
킵그로우 픽셀이 0부터 시작하고 일 5만 원이면 한 달 안에 학습 안정은 어려움 → ROAS 하나로만 평가받지 않도록:
- **매출 지표**: 구매 건수, 광고 기여 매출, ROAS
- **수익 지표**: 메타상 CPA vs 손익분기 CPA
- **구조 개선 지표**: 세트 판매 비중, 객단가 변화, 리뷰 증가
- **다음 달 자산**: 이긴 소재, 쌓인 구매 데이터

**보고 형태 예시**: "광고비 150만 원 → 매출 ○○, 주문당 ○○원 남음, 세트 비중 ○% 상승, 다음 달 개선안 ○○"
