# 더마케터스 외부매체 홍보 리스트 점검 · 유사 플랫폼

목표: 외부 플랫폼과 협력해 '부트캠프'(특히 마케팅 부트캠프)를 검색했을 때 더마케터스가 자연 노출되게 만든다. 기존 18개 리스트를 점검하고, 비슷한 플랫폼을 추가로 정리했다.

## 기존 리스트 점검 결과 (18개)
- 대부분 목적(마케팅 취준생·대외활동·부트캠프 탐색층)에 맞음. **유지 15 · 조건부 2 · 보류 1**
- 리스트에서 빠진 축: **채용 플랫폼의 교육 섹션**(자소설닷컴·캐치·원티드), **마케터 커뮤니티**(아이보스·오픈애즈), **다음 카페**(취업뽀개기)

| 플랫폼 | 판정 | 점검 의견 |
|---|---|---|
| 링커리어 | ✅ 1순위 | 무료 교육 공고 + 커뮤니티(취업/문과 고민 게시판) + 유료 상품(배너·공지·SNS·DM)까지 있어 가장 범용적 |
| 부트텐트 | ✅ 1순위 | 부트캠프를 비교하는 고관여층. '기획·마케팅·경영' 탭에 비용·온오프라인·기간이 나란히 노출 → 입점 여부가 곧 검색 노출 |
| 요즘것들 | ✅ 1순위 | 과거 기수 등록 이력 있음 → 기존 계정 찾기부터 |
| 아웃캠퍼스 | ✅ 1순위 | 마케팅러너 4~7기 무료 광고 이력 → 같은 조건 문의 |
| 독취사 · 스펙업 · 취업대학교 | ✅ | 네이버 카페 → 네이버 검색 '카페' 탭 노출. 홍보 게시판·제휴 규정 확인 필수 |
| 씽유 · 씽굿 | ✅ | 이름은 비슷하지만 **서로 다른 사이트**(씽유 thinkyou.co.kr / 씽굿 thinkcontest.com) — 중복 아님 |
| 올콘 · 스펙토리 · 콘테스트코리아 · 위비티 | ✅ | 공모전·대외활동 사이트. 교육 공고가 등록 기준에 맞는지가 관건 |
| 캠퍼스픽(에브리커리어) | ✅ | 에브리타임 운영사(비누랩스) 서비스. 사람인과 업무협약 기사 있음 |
| 슈퍼루키 | 🔶 조건부 | 운영 중(현재 운영사 리멤버앤컴퍼니). 다만 **채용 중심 + 유료 광고 상품** 위주라 무료 등록이 안 될 수 있음 |
| 이벤터스 | 🔶 조건부 | 행사 플랫폼이라 단순 모집 공고보다 **무료 설명회·오픈클래스** 형태로 올리는 게 맞음 |
| 윈스펙 | ⚠️ 확인 필요 | winspec.co.kr은 NCS 직무교육 **교육업체**(경쟁사 성격). 말한 네이버 카페가 같은 곳인지 미확인 → 카페 URL부터 확인 |
| 캠퍼즈 | ⛔ 보류 | 검색되는 활동 근거가 2015~2019년이 마지막 → 사이트 운영 여부 확인 전까지 제외 권장 |

> ⚠️ 확인 필요: 가입자 수(독취사 3,313,674 · 스펙업 2,117,000 · 취업대학교 881,427 · 아웃캠퍼스 233,170 · 윈스펙 163,180)는 사용자가 준 값이고 실시간 검증 불가. 카페는 회원 수보다 **카페 랭킹·최근 활동량**이 중요하다는 의견도 있음.

## 진행 제안
- **노출 경로를 기준으로 우선순위**: ① 부트캠프 비교 사이트(부트텐트·직무교육관) → 검색 의도가 가장 높음 ② 링커리어·요즘것들 등 공고 페이지 → 구글·네이버 웹 검색에 색인됨 ③ 네이버 카페 → 네이버 카페 탭 노출 ④ 커뮤니티·뉴스레터 → 인지도
- 엑셀에 **판정 · 우선순위 · 노출 경로 · 비용(무료/유료)** 열을 추가하면 컨택 순서를 정하기 쉬움 (점검본 엑셀에 반영)
- 컨택 메일은 [콜드메일 구성](../02_콜드메일/콜드메일_구성.md) 틀 활용 → 오늘 13시 메일 초안과 연결
