# 더마케터스 실습 — 버티컬·외부 매체팀 홍보 전략 (11/24 기준)

더마케터스 1기 실습에서 외부·버티컬 매체 홍보를 맡아, **웨비나로 잠재 고객 확보**와 **더마케터스 2기 직접 모집** 두 갈래로 진행 중. 모든 채널 링크·포스터 QR에 UTM을 나눠 유입·전환을 채널별로 볼 예정.

## 1. 버티컬 매체 유료 광고 협의
- 기준 예산 25만 원. 취준생이 활동하는 플랫폼 중 1·2순위 A사·B사에 직접 연락해 광고 상품·비용 협의
- 목표: 정해진 예산 안에서 최대한 혜택 확보

| 매체 | 기존 제안 | 협의 결과 |
|---|---|---|
| A사 | 게시글 상위 노출 33만 원 | 게시글 상위 노출 + 인스타그램 피드·스토리 홍보 프로모션 **그대로 포함**, **VAT 포함 25만 원** |
| B사 | 게시글 상위 노출 20만 원 | 상위 노출 + **뉴스레터 발송 1회 + 하단 에디터 PICK 배너**를 서비스로, 동일 20만 원 |

- 배운 점: 매체가 제시한 가격을 그대로 받기보다 예산·목적에 맞춰 조건을 협의할 것. B사처럼 **처음부터 여러 광고 상품을 한꺼번에 문의**하면 일부를 서비스로 얹어 주기도 함

> ⚠️ 확인 필요: A사 25만 원 + B사 20만 원 = 45만 원으로 기준 예산 25만 원을 넘음. 예산이 매체별 기준인지, 추가 예산이 승인됐는지 기록해 둘 것 — _(채울 것)_

## 2. 외부 제휴로 웨비나 홍보
- 이 채널들에서는 유료 부트캠프보다 **12/2 무료 웨비나**를 먼저 홍보 → 처음 보는 교육 상품에 바로 결제를 설득하기보다 참여 장벽이 낮은 웨비나로 접점을 만들고 **관심 고객 DB 확보**
- 이전 기획에서 타사를 벤치마킹한 '웨비나로 진입장벽 낮추기'를 실제로 실행

| 채널 | 기준 | 진행 상황(11/24) |
|---|---|---|
| 대학교 취업지원센터 | 세미나 홍보 게시판이 있거나, 재학생 대상 세미나·이벤트 안내를 해 주는 곳 | 전국 리스트 정리 완료 → 사라님이 홍보 협조 메일 발송, **이미 업로드된 곳 있음** |
| 마케팅 동아리·연합동아리 | 마케팅 관련 활동 + 2026년 이후 활동, 인스타그램·메일 수집 | 노션 업로드 → 웨비나 홍보 메일 본문 작성 → 사라님 발송, 웨비나 포스터 디자인 |
| 뉴스레터 | 마케팅·취업 뉴스레터 | 리스트 정리 완료, **11/25 제휴 문의 메일 발송 예정** (무료 협업은 가능성 낮지만 문의 자체는 비용 없음) |

## 3. 더마케터스 2기 직접 모집
- **버티컬 매체 무료 게시글**: 취업·대외활동 매체에 업로드 중 (포스터 사라님, 글 구성·업로드 영이)
- **마케팅 관련 네이버 카페**: 홍보 게시글 + **수강 할인 쿠폰** 제공으로 신청까지 유도
- **더마케터스 1기 수강생 블로그 후기**: 실제 수강 경험으로 과정 특징을 전달 + 2기 할인 쿠폰 안내 → 후기로 신뢰감

## 4. 기존 고객 DB 홍보 메일
- 사수에게 받은 기존 고객 DB 중 **광고 수신 동의 고객**만 대상
- 앞부분은 웨비나, 뒷부분에 더마케터스 2기를 추가로 소개
- 이미 광고성 메시지를 많이 받았을 고객이라 부정적 기억이 남지 않도록 **메일 한 채널로 보수적으로** 접근

## 전략 정리
- **잠재 고객 확보**: 취업지원센터·동아리·뉴스레터 → 참여 장벽이 낮은 웨비나 → 유료 교육에 관심 가질 고객과 접점
- **직접 모집**: 버티컬 매체 유료·무료 광고, 마케팅 커뮤니티, 수강생 후기 → 실제 수강 신청
- **측정**: 채널별 UTM(포스터는 채널별 QR까지 분리) → 게시·발송 현황 + 유입·신청 전환으로 효과 좋은 매체 분석 예정 — _(채울 것: 채널별 유입·신청 수)_
