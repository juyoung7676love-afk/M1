# 노션용 CSV

외부매체 홍보 리스트를 노션 데이터베이스로 옮기기 위한 파일. 원본은 [점검 엑셀](../2026-11-20_더마케터스_외부매체_홍보리스트_점검.xlsx).

- 첫 줄이 머리글(속성 이름), 셀 안 줄바꿈·빈 행 없음, 빈 값은 비워 둠
- 노션에서 **가져오기(Import) → CSV**로 새 데이터베이스를 만들거나, 기존 데이터베이스의 `•••` → **CSV로 병합(Merge with CSV)** 사용

| 파일 | 내용 |
|---|---|
| 01_무료게시_플랫폼.csv | 무료 게시 플랫폼 21곳 |
| 02_뉴스레터_협업.csv | 마케팅 뉴스레터 11곳 |
| 03_대학_학과_연락처.csv | 경영·광고홍보 학과 사무실 34곳 |

| 05_취업지원센터_연락처.csv | 전국 취업지원센터 58곳 |
| 06_기존리스트_우선순위.csv | 기존 18개 플랫폼 |
| 07_추가추천_우선순위.csv | 추가 추천 16곳 |
