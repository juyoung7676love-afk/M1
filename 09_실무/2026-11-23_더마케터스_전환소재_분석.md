# 더마케터스 2기 — 전환이 난 인스타 스토리 소재 2개 분석

두 소재 모두 광고처럼 보이지 않는 스토리 콘텐츠이고, 취준생의 '경험이 없어서 경험을 못 쌓는' 불안을 정확히 건드렸다. 해결책도 강의가 아니라 '경험' 자체로 제시했다.

## 소재 A — POV 밈형 (문제 제기)
- 카피: "POV: 마케팅 면접에서 광고 실무 경험 물어볼 때" + 당황해 눈물 맺힌 정장 차림 지원자 클로즈업
- **1초 안에 상황이 이해됨**: 텍스트 한 줄 + 표정 하나. 스토리를 넘기는 속도에서도 읽힘
- **POV(1인칭) 밈 포맷**: 보는 사람이 자기 얘기로 받아들임. 릴스·스토리에서 익숙한 형식이라 광고 거부감이 적음
- **불안을 아주 구체적으로 짚음**: '마케팅 경험'이 아니라 **'광고 실무 경험'** → 더마케터스가 주는 것(실제 광고 집행)과 1:1로 맞물림
- 해결책은 화면에 없음 → 궁금증이 '자세히 보기' 클릭으로 이어짐 (랜딩페이지가 답을 줌)

## 소재 B — 취준생 일기형 (공감 → 해결 서사)
- 길거리 사진 위에 취준생 독백 텍스트, 링크 스티커 "더마케터스2기 지원하기"
- **친구 스토리처럼 보임**: 구어체·오타·'ㅠㅠ', 휴대폰으로 찍은 거리 사진 → 광고 느낌이 거의 없는 UGC 스타일
- **서사 구조**: 계획(인턴 지원) → 좌절(인턴도 경험이 있어야 붙음 = **경험의 역설**) → 발견(스펙 안 보는 4주 마케터 인턴) → 구체적 혜택 → 결심(2027 상반기 목표)
- **망설이는 이유를 본문에서 먼저 해결**: '비전공·무스펙이어도 됨'(지원동기만 있으면 됨), '광고비 지원', 'GA 데이터 분석 가능' → 비용·자격 걱정과 '진짜 실무냐'는 의심을 동시에 해소
- **CTA가 두 번**: 콘텐츠 안 링크 스티커(지원하기) + 하단 '자세히 보기'

## 두 소재의 공통 포인트
- **네이티브 포맷**: 둘 다 '광고'라기보다 스토리 콘텐츠. 스토리 지면에서 넘기기 전에 읽힘
- **타깃의 언어**: "비전공무스펙", "서합", "포폴 업글" 같은 취준생 말투 → 자기 얘기라고 느낌
- **핵심 불안 = 실무 경험 없음**: 더마케터스의 차별점(실제 광고 집행·광고비 지원·GA 데이터)이 이 불안의 정답으로 바로 연결
- **판매가 아니라 '경험' 제안**: 가격·할인·강사 소개가 없음. "포폴 만들어서 붙자"는 결과 이미지만 보여 줌
- 소구 유형으로 보면 A는 **문제제기형**, B는 **실제후기형(을 흉내 낸 UGC)** → [광고 소재 소구 유형](../04_기초개념/광고소재_소구유형.md)

## 다음 테스트 아이디어 (한 번에 한 변수만)
- A 변형: 같은 POV 포맷으로 상황만 바꾸기 — "POV: 자소서에 '성과 수치' 쓰라는데 쓸 게 없을 때", "POV: 인턴 공고에 '광고 집행 경험자 우대' 보일 때"
- B 변형: 같은 일기 서사로 화자만 바꾸기 — 이직러("3년차 영업인데 마케터로 옮기고 싶어서"), 4학년 막학기
- A의 끝 장면에 해결 컷 1장 추가(4주 뒤 포트폴리오 숫자) vs 지금처럼 궁금증만 남기기 → 클릭률·전환율 비교
- 테스트 방법은 [메타 소재 테스트](../05_메타/소재_테스트.md) 기준: 광고 세트 하나에 확실히 다른 소재 2~3개, 7일 이상 수정 없이

> ⚠️ 확인 필요: 전환 수·CPA·CTR 등 수치가 없어 '왜 잘 됐는지'는 소재 내용 기준 해석. 전환 수가 적으면 우연일 수 있으니 노출·클릭·전환 수치를 함께 기록해 둘 것 — _(채울 것: 소재별 노출·CTR·전환·CPA)_
> ⚠️ 확인 필요: 소재 B는 실제 수강생 후기처럼 읽힘. 실제 후기가 아니라면 '후기'로 오해하지 않게 '광고' 표기가 붙는 광고 지면에서만 쓰고, 실제 수강생 후기라고 주장하는 문구는 피할 것(표시광고법상 기만 광고 우려)
